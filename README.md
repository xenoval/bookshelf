# Полка: трекер чтения

Веб-приложение для личной книжной полки. Книги ищутся через открытый API [Open Library](https://openlibrary.org/developers/api). Найденную книгу можно добавить на полку, отметить статус («хочу прочитать», «читаю», «прочитано»), вести заметки по ходу чтения и написать отзыв с оценкой.

## Возможности

- Поиск книг по названию или автору во внешнем API Open Library
- Обложки, авторы и год издания. Пока обложка грузится, если её нет или сервер обложек недоступен, вместо неё показывается заглушка в стиле книжной обложки с названием и автором
- **Личные рекомендации** на основе книг, оценённых на 4–5 звёзд; пока оценок нет, показываются популярные книги
- Полка с разделами «Хочу», «Читаю», «Прочитано» в нижнем меню
- **Заметки** к книгам в разделе «Читаю»: дневник мыслей и цитат с датами
- **Отзывы** к прочитанным книгам: оценка от 1 до 5 звёзд и текст
- **Настройки**: тема (как в системе, светлая, тёмная, кремовая, звёздная с ночным небом) и язык интерфейса (русский, английский). Выбор запоминается в браузере
- Адаптивная вёрстка: на телефоне окна выезжают снизу

## Как работают рекомендации

1. Берутся книги с оценкой 4 или 5 (до трёх самых любимых).
2. Для каждой из Open Library загружаются темы, например «Fiction, dystopian». Служебные темы вроде «Accessible book» отбрасываются.
3. По каждой теме ищутся книги с самым высоким рейтингом.
4. Результаты разных книг чередуются, а то, что уже есть на полке, и книги тех же авторов убираются.

Ответы Open Library кэшируются в памяти на час, поэтому повторное открытие подборки происходит мгновенно.

## Стек

| Часть | Технологии |
|---|---|
| Бэкенд | Python 3.12, FastAPI, SQLAlchemy 2.0, SQLite, httpx |
| Фронтенд | HTML, CSS (Grid, Flexbox, custom properties), JavaScript без фреймворков |
| Внешний API | Open Library Search API, Covers API |

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux
pip install -r requirements.txt
uvicorn backend.main:app --reload
```

Приложение откроется на http://localhost:8000, документация API на http://localhost:8000/docs.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/search?q=...` | Поиск книг в Open Library |
| GET | `/api/recommendations` | Подборка на основе оценок |
| GET | `/api/books?status=...` | Книги на полке (фильтр необязателен) |
| POST | `/api/books` | Добавить книгу на полку |
| PATCH | `/api/books/{id}` | Изменить статус, оценку или отзыв |
| DELETE | `/api/books/{id}` | Убрать книгу с полки вместе с заметками |
| POST | `/api/books/{id}/notes` | Добавить заметку к книге |
| DELETE | `/api/notes/{id}` | Удалить заметку |
| GET | `/api/stats` | Количество книг по статусам |

## Структура

```
backend/
  main.py             — FastAPI-приложение и эндпоинты
  database.py         — подключение к SQLite
  models.py           — таблицы базы данных: книги и заметки
  schemas.py          — Pydantic-схемы запросов и ответов
  openlibrary.py      — клиент внешнего API с кэшем
  recommendations.py  — алгоритм рекомендаций
frontend/
  index.html          — разметка
  style.css           — стили и цветовые темы
  i18n.js             — переводы интерфейса (ru, en)
  app.js              — логика интерфейса
  img/                — звёзды для звёздной темы (SVG)
```
